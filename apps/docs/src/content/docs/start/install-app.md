YAPCO jest *progresywną aplikacją internetową*: przeglądarka może ją zainstalować jak zwykły
program na komputerze lub telefonie, a po pierwszej wizycie otwiera się i działa bez internetu.

## Instalacja

- **Chrome lub Edge na komputerze**: ikona instalacji po prawej stronie paska adresu albo menu
  → *Przesyłaj, zapisuj i udostępniaj* → *Zainstaluj stronę jako aplikację*.
- **Android (Chrome)**: menu → *Dodaj do ekranu głównego* → *Zainstaluj*.
- **iPhone i iPad (Safari)**: *Udostępnij* → *Do ekranu początkowego*.

Instalacja wymaga HTTPS (strona w internecie) albo `localhost`. Przeglądarki nie proponują jej
dla zwykłego adresu `http://` w sieci domowej.

## Co działa offline

| Działa offline | Wymaga internetu |
| --- | --- |
| Lista planerów, projektant, podgląd, treści, tłumaczenia | **Utwórz PDF** (usługa eksportu) |
| Drukowanie z przeglądarki (*Widok wydruku*) | Pierwsze otwarcie aplikacji |
| Kopie JSON i import | Ta dokumentacja |

## Aktualizacje

Aplikacja przy każdym otwarciu z dostępem do internetu sprawdza, czy jest nowa wersja, i używa
jej od następnej wizyty. Aktualizacje nie zmieniają Twoich planerów.
