This walks through the whole path once: create a planner, look at it, print a month. It works
the same on a hosted site and on your own computer.

## 1. Create the planner

Open the app. The start page (the *dashboard*) has the **New planner** form.

![The dashboard with the new-planner form and three planners](/docs/screens/dashboard.png)

1. **Template**: *Day by Day* for a day planner, *Week by Week* for a weekly one.
2. **Edition**: *Basic*, *Balance* or *Recovery Edition*
   ([what is the difference?](/docs/en/guides/editions/)). **Modules** below it add or remove
   single parts.
3. **Format**: A4 or A5. You can change it later; your edits carry over.
4. **Planner language**: Polish or English, independent of the interface language.
5. **Start date** and **Length**. Tick *Undated* to write the dates by hand.
6. **Name** (also used for the PDF file names), then **Create planner**.

The page count and the spine width update as you change the settings.

## 2. Look at it

The planner opens in the **Design** screen. Use the tabs at the top:

- **Preview**: spreads at real size. Switch on **Example filling** to see each page filled in
  by hand, in grey.
- **Design**: change pages and blocks ([the designer](/docs/en/guides/designer/)).
- **Content** and **Translations**: quotes, prompts and texts in both languages.

Everything saves by itself ("All changes saved").

## 3. Print one month

1. Click **Export** (top right).
2. **What to print**: pick one month. Months always fill whole sheets, so you can file them one
   at a time.
3. **How you print**: *Two-sided, automatic* if your printer prints both sides; otherwise
   *Two-sided, by hand*.
4. **Create PDF**. The file downloads.
5. Print at **Actual size / 100 %**, never "fit to page".

The first time, print the **calibration sheet** as well: see
[Printing at home](/docs/en/guides/printing/).

## 4. Keep a backup

Planners live only in this browser. Once a week: **Export → Save planner as JSON**. See
[Backups and moving planners](/docs/en/guides/backups/).
