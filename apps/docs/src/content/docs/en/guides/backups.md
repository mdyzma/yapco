Planners live only in the browser where you made them. Clearing the browsing data for the site
deletes them, so keep backups.

## Back up

**Export → Save planner as JSON**. One file per planner, with everything: pages, your edits,
content and settings. Keep the files in a folder that is backed up (OneDrive, Google Drive…).

Do it weekly, and always before updating a self-hosted site.

## Restore or move

Dashboard → **Import JSON…** → pick the file. It is added as a **new** planner; nothing is
overwritten. The same file moves a planner to another browser, computer, or from `localhost` to a
hosted site.

## Share only the layout

**Export → Save template as JSON** saves the layout without names, dates or personal values.
Importing it creates a fresh planner from that template.

## Duplicate

**Duplicate** on the dashboard makes a copy in the same browser, for example to try other
modules without touching the original.

## Limits

Import accepts JSON files up to 10 MB that are a YAPCO planner or template.
